# Shenwa Agent

深挖AI - AI 深度投研分析师，基于深挖平台 API 生成结构化投研报告。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **深度调查报告**：公司研究、行业分析、事件复盘，异步生成结构化调研报告。
- **全市场报告**：查看公共/私有/收藏报告列表，读取报告详情原文。
- **市场复盘 & 卖方日报**：获取最新深挖市场快报与全市场卖方日报。
- **乖离率分析**：下载行业乖离率数据（VIP2）。
- **知识库检索**：检索新闻、脱水券商研报、卖方报告（VIP2）。
- **PDF 下载**：直接下载已排版好的报告 PDF。

## 使用示例

- 帮我深挖一下宁德时代最近的动作，生成一份公司研究报告
- 给我今天最新的深挖市场复盘和全市场卖方日报
- 查一下最新的行业乖离率数据

## 首次使用：配置深挖账号凭据

本专家包**不包含任何账号信息**。使用者只需提供自己的**注册手机号**——**不需要邀请码，也不需要密码**；未配置时调用深挖接口会直接报错并提示配置方式（不会回退到任何内置账号）。

任选一种方式：

**方式 1 · 本地凭据文件（推荐）**

创建 `~/.workbuddy/shenwa_credentials.json`：

```json
{"userID": "注册手机号"}
```

**方式 2 · 环境变量**

设置 `SHENWA_USER_ID` = 注册手机号。（`SHENWA_INVITE_CODE` 已废弃，无需设置）

凭据一律存放在**专家包之外**，不会被随包分发；账号类型（是否 adm）与剩余配额可用 `user_info` 接口查看。
> **为什么只要手机号？** 深挖接口自 2026-09-27 起已不再校验邀请码，只提交注册手机号即可登录成功。
> 若你使用的版本仍在索要邀请码，说明拿到的副本较旧，请向分发者索取更新后的专家包。
> 还没有深挖账号？联系微信 **shenwa4119**（公众号：**真深挖者也**）开号或充值。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\songj\.workbuddy\plugins\marketplaces\my-experts\plugins/shenwa-agent/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir> <output-dir>
```

脚本位于 `expert-manager/scripts/`，以**目录为位置参数**（无 `--help`）。打包前会自动 validate；分发给他人时，对方在「专家中心 → 我的专家 → 导入 .zip」安装。

> ⚠️ 打包前请确认包内**不含任何账号凭据**（可用 `grep -rn "<手机号>\|<邀请码>" <expert-dir>` 自查）。
