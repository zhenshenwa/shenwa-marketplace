# Shenwa Hybrid Research · 深挖混合投研模式

把「AI 深度研究报告能力（深挖 Shenwa）」与「结构化金融数据能力（泛金融数据 Skill）」组合成一个职责清晰、可校验、可个性化、可复制的投研智能体模式。

## 类型

Agent 型（单个 AI 专家）

## 核心设计

- **50/50 分工**：深挖出分析主体（逻辑、格局、推演），数据源做事实底座与校验层；**校验表计入数据源那 50%**。
- **四层架构**：L1 偏好层（客户唯一可改）→ L2 路由层（冻结）→ L3 能力层（冻结）→ L4 输出层（由偏好驱动）。改偏好只改变输出长什么样，不会破坏能力调度。
- **数字分层采信**：已披露财报科目可引用；推算类比率、估值类数字、阈值价格类不得引用，以数据源为准。深挖的价值在于分析框架，而非数字。
- **偏好外置**：18 项偏好 / 57 个选项 / 4 套开箱预设；偏好文件带版本号、可回滚、带修正日志。

## 功能

1. **七步闭环 SOP**：任务受理 → 偏好注入 → 路由判定 → 并行取数 → 交叉校验 → 成稿交付 → 归档修正。
2. **路由决策树**：先定标的层级再定任务类型；从 17 个实测模板中选型；发布后用 `stocks` 挂载数自动校验层级错配。
3. **两轮交叉校验**：先数据源内部一致性（轮 1），再深挖 vs 数据源（轮 2）；拦截级项直接剔除。
4. **5 类开箱任务卡**：公司深度研究 / 行业对比 / 每日复盘 / 量化因子分析 / 趋势异动跟踪。
5. **完整引用深挖原文**，数字以数据源为准，两者并行不冲突。

## 使用示例

- 以「价值稳健」偏好，对宁德时代做一份公司深度研究，附校验表
- 帮我对比比亚迪与宁德时代的电池业务盈利能力
- 用「趋势交易」偏好跟踪我关注池的异动，并说明哪些数字需要复核

## 首次使用：配置深挖账号凭据

本专家包**不包含任何账号信息**。使用者须自行提供深挖账号的注册手机号与邀请码，二者缺一不可；未配置时调用深挖接口会直接报错并提示配置方式（不会回退到任何内置账号）。

任选一种方式：

**方式 1 · 本地凭据文件（推荐）**

创建 `~/.workbuddy/shenwa_credentials.json`：

```json
{"userID": "注册手机号", "inviteCode": "邀请码"}
```

**方式 2 · 环境变量**

设置 `SHENWA_USER_ID`（注册手机号）与 `SHENWA_INVITE_CODE`（邀请码）。

凭据一律存放在**专家包之外**，不会被随包分发；账号类型（是否 adm）与剩余配额可用 `user_info` 接口查看。

## 安装


```bash

```
