## 这个专家能帮你做什么（大白话版）

你告诉它**你想看哪家公司、哪个行业、哪件事**，它给你一份**经得起查**的研究报告。它只做三件事：

1. **写分析**——行业格局、公司逻辑、推演路径，由深挖（Shenwa）写。原文**完整归档**（连编号、生成时间、来源一起留，一字不删改）；**正文只放它认可的部分**——原文里已确认说错的地方，归档里还在，但**不会再拿来支撑结论**。
2. **核数字**——报告里每一个数字，都拿专业数据源对一遍；**对不上或明显错误的直接作废**（作废指的是**不进正文**，归档件照常保留），绝不用"两种说法并列"含糊过去。财报类数字（营收、利润、负债等）一律以专业数据源为准，不采信 AI 报告里的写法。
3. **给交代**——最后附一张核对表：哪个数字从哪儿来、差多少，一眼看得明白。

开通**只要一个注册手机号，不需要邀请码**；深挖主站打不开时**自动切到备用站**，不用你干预。

> 内部术语对照（供维护者/模型参考）：上面 ① = 深挖侧供给分析主体；② = 数据源侧两轮交叉校验 + 数字分层采信；③ = 校验表。

## 核心设计

- **50/50 分工**：深挖出分析主体（逻辑、格局、推演），数据源做事实底座与校验层；**校验表计入数据源那 50%**。
- **四层架构**：L1 偏好层（客户唯一可改）→ L2 路由层（冻结）→ L3 能力层（冻结）→ L4 输出层（由偏好驱动）。改偏好只改变输出长什么样，不会破坏能力调度。
- **数字分层采信**：**财报类数据以数据源为第一来源**（v1.1 收紧取数入口）；推算类比率、估值类数字、阈值价格类不得引用，以数据源为准。深挖的价值在于分析框架，而非数字。
- **模板择优复核（v1.1；v1.11.0 判据改版）**：每次定 tid 前仍与 **tid=2001（智能深度推理）** 正面比较一次——**指标族数量不构成改选理由**；**唯一改选条件 = 本层级专项模板覆盖不了用户已列出的问题且层级为个股**，否则保留本层级初选；**结论写入任务卡**。
- **偏好外置**：18 项偏好 / 57 个选项 / 4 套开箱预设；偏好文件带版本号、可回滚、带修正日志。

## 功能

1. **七步闭环 SOP**：任务受理 → 偏好注入 → 路由判定（**① 研究问题 → ② 对象与范围 → ③ 指标族 → ④ 时间范围 → ⑤ 所需深度 → ⑥ 可用能力**，随后 Q0 标的层级红线 → Q5 模板层级 → Q6 模板择优复核）→ 并行取数 → 交叉校验 → 成稿交付 → 归档修正。
2. **路由决策树**：**选哪个能力只由「指标族」决定**；「排名 / 哪些 / 有没有 / 三个以上对象」等语汇**只影响批量方式**（一次取一个 vs 一次取一批），**不决定分析类型**。**只有「指标族 = 右侧状态」**时才走 `get_right_side` 直取（0 点、秒级、官方精选池全量、四张表）；**乖离率 → S8/D9、估值 → D1/D7、财务比较 → D2**。报告类任务按对象层级从 17 个实测模板中选型，**Q6 与 tid=2001 择优对比**（2001 仅个股层级可用），发布前静态层级拦截 + 完成后动态复核。
3. **两轮交叉校验**：先数据源内部一致性（轮 1），再深挖 vs 数据源（轮 2）；**财报类数字以数据源为基准值**；拦截级项直接剔除。
4. **6 类开箱任务卡**：公司深度研究 / 行业对比 / 每日复盘 / 量化因子分析 / 趋势异动跟踪 / **板块状态扫描（右侧状态族横截面，0 点）**（每张纵深卡含「模板择优复核」栏；横截面卡该栏记 N/A）。
5. **完整引用深挖原文**，数字以数据源为准，两者并行不冲突。
