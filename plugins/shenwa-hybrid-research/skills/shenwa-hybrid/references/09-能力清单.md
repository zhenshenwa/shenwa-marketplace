## 〇、怎么用这张清单

1. **先看状态，再看能力名。** 状态四态：
   - `verified_supported` —— 已验证支持（有实测证据，可直接承诺）
   - `conditional` —— 条件支持（有实现但有前提：权限 / 口径 / 时效，须先满足前提）
   - `unverified` —— 未验证（存在但不能承诺；未验证 ≠ 不存在）
   - `unavailable` —— 不可用（无可执行依据，明确不做）
2. **未验证 ≠ 不存在**，但**不能直接承诺支持**。
3. **权限是硬门槛**：标 `VIP2` / `ADM` 的能力，无权限时返回 `status=AUT`。
4. **缺失时的处理方式写在最后一列**，照它执行，不要临场发明。

## 一、编号口径（v1.7.0 统一）

**冲突**：「D4」在原文档中同时代表三种东西：① 数据能力「公告与事件」（02 / SKILL / 04）；② 数据能力「技术指标」（趋势异动跟踪 / 量化因子分析 / 04 的数据清单）；③ 偏好选项「可视化」（03A / 03B，`output.include_visual`）。

**根因**：偏好选项组（A/B/C/D/E）与数据能力编号（D1~D8）**共用字母 D**，且技术指标从未获得自己的编号，被就近写成了 D4。

**解法**：
- ① 数据能力编号 D1~D8 **含义保持不变**（向后者兼容，不改语义）；
- ② **新增 D9 = 技术指标**，原被误标为 D4 的全部位置改指 D9；
- ③ **偏好选项组 D 更名为 F**（F1~F6，产出形态）——该字母只是**人读标签**，配置字段（`output.*` / `datasource.*`）不变，故是纯标签变更，不破坏配置兼容性。

**不改写的部分**：历史记录（examples/ 下的原始任务卡与报告）**一律不改写**——它们记录的是当时的口径。

## 五、本地保存 vs 服务端「公开 / 私有」

**问题**：本地保存与服务端的「公开 / 私有」是不是一回事？

**结论**：**不是一回事，且不能互相承诺。**

| 维度 | 内容 | 可控性 | 依据 | 状态 |
|---|---|---|---|---|
| `local_save` | 报告原文由本包落在工作区，形成「归档件」（完整保留全文，含已确认错误段落） | **完全本地可控** | 本包归档写入路径与文件名由本地流程决定（见 05-输出规范「归档件」节） | `verified_supported` |
| `server_state` | `report_status` 返回 `public` / `private` / `error`；`report_list` 的 `type` 可取值 `public` / `self` / `collect` / `history` | **服务端结果状态，不是客户端选项** | `POST /api/manage/wfStartPublish` 的参数为 tid / question / text，**无任何可见性（visibility / public / private / scope）参数**；脚本 `shenwa_api.py` 的 APIS 注册表同样无该参数 | `verified_supported` |

**不得承诺**：
- **不能承诺「私有发布」** —— 没有可指定的发布参数；`private` 是服务端给出的结果态。
- **不能承诺「服务端不保存」** —— 发布即入库，没有「发布但不落库」的参数。
- **不能承诺「删除即彻底清除」** —— 有 `delete_report`，但删除是否彻底、是否残留副本**无证据**。

**可执行替代**：
- **想要私有可见**：在交付物中**本地归档**（可控），并说明服务端可见范围由服务端决定、本包不承诺。
- **想要不落服务端**：**做不到**。可选的最近似动作是发布后调用 `delete_report`，须**如实告知**「已发布并随后删除，删除彻底性无证据」。

**与偏好项的关系**：偏好项 `E3 archive_mode` 的 `private` / `public` / `discard` 三档，**只有 `discard` 需要额外说明**：它无法实现为「服务端不保存」，只能实现为「发布后删除」。

## 六、量化 / 回测 / 跨市场：按实际链路标注

### 量化 / 因子

- **主张**：「量化因子」画像**只有画像名称，不等于完整具备量化能力**。
- **状态**：`conditional`
- **实际链路**：D2 财务质量因子原始科目 → D1 估值倍数与历史分位 → D9 动量 / 波动率 / 技术类因子 → D3 流动性 / 资金面因子 → D6 股票池构建与截面排序 → D8 因子表与分位整理
- **已支持**：**因子暴露与历史 / 同业分位**（可拼装，属于条件支持）
- **未支持**：**回测**（无净值 / 组合 / 换手成本链路） / **多因子回归 / IC 计算**（本包无实现，服务端无对应接口）
- **诚实规则**：**不得因存在「量化因子」画像名称就声称完整具备量化能力**；产出限于「因子暴露表 + 分位 + 经济逻辑解释」。

### 回测

- **主张**：本包**不提供回测**。
- **状态**：`unavailable`
- **已支持**：—
- **未支持**：历史净值回放 / 交易成本建模 / 组合再平衡 / 绩效归因
- **诚实规则**：不得以任何措辞暗示具备回测能力；被问到时如实说明并给替代（因子暴露 + 分位）。

### 跨市场

- **主张**：跨市场**仅有配置项，未经实测**。
- **状态**：`unverified`
- **实际链路**：偏好 C1 = [A] / [A,HK] / [A,HK,US]
- **已支持**：**仅 A 股**为已验证支持
- **未支持**：港股财务 / 行情（未实测） / 美股财务 / 行情（未实测） / AH 溢价对比（未实测）
- **诚实规则**：被问及港美股时，**先声明未验证**，再说明可尝试、结果不作承诺；**不得**因配置项支持 `[A,HK,US]` 就宣称具备跨市场分析能力。
