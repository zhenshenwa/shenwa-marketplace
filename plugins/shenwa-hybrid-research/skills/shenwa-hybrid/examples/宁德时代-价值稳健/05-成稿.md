## 一、核心分析框架

### 1. 财务模型（DCF+PB-ROE+股息率修正）

适用场景：动力电池龙头稳定增长型企业，侧重自由现金流、ROE、安全边际对估值的影响

核心变量：

- 营收增速（CAGR）：近3年历史增长18%+储能业务增长调整
- 利润率趋势：毛利率18%-22%、净利率8%-11%（锂价成本影响）
- 资本效率：ROE 12.8%（2026H1）、ROIC 9.2%，均高于WACC 8.5%

估值逻辑：

$$\text{目标价} = \text{DCF基础值} \times (1 + \frac{\Delta \text{财务指标}}{\text{基线}})$$

- Δ财务指标弹性系数：ROE每提升1pct→DCF估值+4%，自由现金流/净利润每提升0.1→DCF估值+2%

| 财务指标变化 | DCF估值影响 | 估值倍数调整 |
| --- | --- | --- |
| 营收CAGR维持18% | +20% | PE 18x → 21x |
| ROE提升至15% | +12% | PB 3.2x → 3.7x |
| 分红率提升至30% | +8% | 股息率1.2% → 1.6% |
| 毛利率下滑3pct | -14% | PE 18x → 15x |

### 2. 新闻事件驱动模型（PEG+事件弹性系数）

适用场景：政策/技术/供应链突发事件，股价催化与下行风险测算

核心变量：

- 事件类型：贸易政策、技术突破、上游原材料波动
- 事件强度：直接影响营收的比例

估值逻辑：

$$\Delta P = P_0 \times (1 + \alpha \times \frac{\Delta \text{营收}}{\text{基线}})$$
