# 估值修订示例（v1.6.0）

> **对应旧版**：`07-D7补充与独立估值推导.md（及其沿用件 08-成稿v2-含独立估值.md）`（**不修改、不删除**，原样保留）

## 旧版存在的问题

1. 把「有无 D7」当作能否估值的**总开关**：无 D7 即拒绝输出任何价格区间 —— 实际上当时**绝对法（DCF）的输入已经齐备**，只是不能做相对估值交叉验证。
2. 要求「估值必须至少两种方法」，把方法数量当成**准入条件**；单方法即使输入齐备也不输出。
3. 规定「任一锚点偏差 > 5% → 其后全部估值推演**整链作废**」，作废范围过宽，会牵连与该锚点无关的结论。
4. 第四节把「三方法收敛于 293~301」当作结论可信的证据 —— **接近程度 ≠ 准确度**；同一份报告的中性值也曾「碰巧落在」合理区间内，而其三个输入锚点全部失真。
5. DCF 敞口只写「加回净现金 2,230.24 亿元」，**未逐项列出**少数股东权益 / 优先股 / 其他权益调整，也未说明缺项会带来的方向性偏差。

## 本版改了什么

1. 改为**逐方法检查必要输入与适用条件**；D7 只是相对估值类方法（相对 PE / PB-ROE / PS）的必要输入，缺它**只停用该类方法**。
2. **取消「至少两种方法」**：齐备必要输入的方法即可在其**边界**内输出，**单方法同样有效**。
3. 锚点失真**只作废真正依赖该锚点**的推演，与该锚点无关的结论照常保留；不因某个无关指标偏差而废弃整份报告。
4. 把多方法的作用改为**解释差异**（输入 / 口径 / 时点 / 假设不同），并明示接近程度不等于准确度。
5. 企业价值 → 股权价值改为**逐项桥梁**；缺次要调整项时**按零处理但显式声明**并标 `qualified=False`，说明可能的**高估**方向。
6. 补上**输入分类标注**（历史观测 / 已披露事实 / 未来假设 / 计算结果）与**永续公式守卫**（g ≥ 折现率时阻止计算）。

> **版本关系**：本修订版与旧版**并存**，**不覆盖、不删除** `07-D7补充与独立估值推导.md` 与 `08-成稿v2-含独立估值.md`。

## 二、按 v1.6.0 口径重述这条估值链

### 2.1 输入分类（先把「是什么」标清楚）

| 输入 | 数值 | 类别 | 说明 |
|---|---|---|---|
| FCFF（基期 FY2025） | 461.58 亿元 | `[已披露]` | 年度口径，规避单季波动 |
| 货币资金 | 3,720.53 亿元 | `[已披露]` | 财报科目 |
| 有息负债 | 1,490.29 亿元 | `[已披露]` | 财报科目 |
| 总股本 | 46.2724 亿股 | `[已披露]` | — |
| 现价 / PE / PB | 293.50 元 / 15.98x / 3.64 | `[历史观测]` | 2026-09-24 时点 |
| ROE（TTM） | 22.41% | `[历史观测]` | 历史区间值 |
| **WACC** | 8.0% / 8.5% / 9.0% | **`[预测假设]`** | 数据源**不提供**，属假设 |
| **5 年 FCFF 增速** | 10% / 15% / 20% | **`[预测假设]`** | 同上 |
| **永续增长率 g** | 2.0% / 2.5% / 3.0% | **`[预测假设]`** | 同上 |
| 隐含价格 / 每股价值 | 251.6 ~ 465.4 元 | `[计算结果]` | 随假设变动 |

> ⚠️ **旧版第 108 行的假设声明方向是对的**（"WACC、增长率均为假设，非事实"），本版把它**制度化**：
> 假设必须单列成类，不得与已披露数字混在同一张输入表里不加区分。

### 2.2 现金流与折现率的配对（先配对，再计算）

| 本报告使用 | 现金流 | 折现率 | 折出 | 之后 |
|---|---|---|---|---|
| 方法 4 | **FCFF**（461.58 亿，**不扣利息**） | **WACC**（8.0/8.5/9.0%） | **企业价值** | 必须走 2.3 的桥 |
| 反例（未使用） | FCFF | 股权资本成本 Ke | — | ❌ **错配**：Ke > WACC → 分母偏大 → 系统性**低估**企业价值，本版不允许 |

### 2.3 企业价值 → 股权价值（本版新增：逐项桥梁）

以旧版**中性情景**（WACC 8.5%、增速 15%、g 2.5%）的隐含每股 335.7 元为已知结果，**反推**其企业价值并复核桥梁：

```
企业价值 EV = 335.7 元 × 46.2724 亿股 − 2,230.24 亿元 = 13,303.40 亿元
股权价值   = EV 13,303.40 ＋ 货币资金 3,720.53 − 有息负债 1,490.29
             − 少数股东权益 ？ − 优先股权益 ？ ± 其他调整 ？
           = 15,531.14 亿元（**未扣次要调整项**）
每股价值   = 15,531.14 / 46.2724 = 335.70 元  ✓ 与旧版一致
```

**但本版必须补一句边界说明**：

> ⚠️ 该桥梁的**必要调整项齐备**（现金 + 有息债务 + 总股本），但**次要调整项未提供**
> （少数股东权益 / 优先股权益 / 其他权益调整）→ 按零处理并**显式声明**
> （`valuation.py::equity_bridge` 返回 `complete=True, qualified=False`）。
> 若这些项实际存在，**本结果会高估股权价值**。
> **旧版 07 没有写出这一句**，因此它给出的「每股价值」在口径上是不完整的。

### 2.4 永续公式的守卫

| 情景 | WACC | g | g vs WACC | 处理 |
|---|---|---|---|---|
| 保守 | 9.0% | 2.0% | g < r | 可计算 |
| 中性 | 8.5% | 2.5% | g < r | 可计算 |
| 乐观 | 8.0% | 3.0% | g < r | 可计算 |
| **反例（本版新增）** | 9.0% | **9.0%** | **g = r** | ❌ **阻止计算**：分母 = 0，会得 ∞；须改用显式预测期 + 终值倍数或修正假设 |

### 2.5 若把历史 CAGR 用于未来（本版新增的强制标注）

若用历史营收 CAGR 外推（本示例取 **13.53%**、期限 **10 年**）：

> 将 **近三年营收** 的 CAGR **13.53%** 外推至未来 **10** 年：这是 **预测假设**，
> **不是已验证的未来增长率**。
> 适用理由：产能投放与订单可见度延续。
> 敏感性：±3pct → 每股价值约 **±18%**。

⚠️ **三条（期限 / 理由 / 敏感性）缺一即为不齐备**，此时不允许把它写进估值链；
且无论补得多完整，该值**永不**被标为「已验证」。

### 2.6 方法适用条件矩阵（取代「必须有 D7」「至少两种方法」）

| 方法 | 必要输入 | 本示例是否齐备 | 结论 |
|---|---|---|---|
| FCFF 折现 | FCFF 预测、WACC、有息债务、现金/非经营资产、总股本 | ✅ 齐备 | **按边界输出**（须附 2.3 的边界说明） |
| 股息率法 | 每股股息、要求股息率 | ✅ 齐备 | 输出（要求股息率为假设） |
| PB-ROE | PB、ROE、要求回报 | ✅ 齐备 | 输出（要求回报为假设） |
| 相对 PE | 每股收益、可比倍数 | ✅ 齐备（**依赖 D7**） | 输出；**若本次未取 D7 → 只停用本方法**，其余不受影响 |
| FCFE 折现 | FCFE 预测、Ke、总股本 | ❌ 缺 FCFE 与 Ke | **只停用本方法**（不影响上面三种） |
| PS | 每股营收、可比 PS | ❌ 缺 | 只停用本方法 |

> **准入只看必要输入**：齐备的方法**一个也算数**；不再要求"至少两种"，也不再因缺 D7 而拒绝输出任何价格区间。
> **一方法输入不足时只停该方法**——这正是旧版 `C15/C17` 最需要修正的地方。

### 2.7 多方法差异：解释，不剔除

四方法的保守/中性/乐观值（沿用旧版 `07` 第三节的表）**全部保留**：

| 方法 | 保守 | 中性 | 乐观 |
|---|---|---|---|
| 股息率法 | 256.8 | 293.4 | 357.2 |
| PB-ROE | 278.0 | 301.2 | 328.5 |
| 相对 PE | 244.9 | 293.9 | 367.4 |
| DCF（假设驱动） | 251.6 | 335.7 | 465.4 |

差异来源（本版必须写明）：

- **DCF 的离散度最大**：它同时依赖 WACC、增速、永续 g 三个**假设**，永续项会把微小假设差放大；且所设 WACC 高于该公司实际 ROIC 8.37%，"资本回报高于资金成本"这一前提在当前时点本身脆弱。
- **三种相对/收益率类方法彼此接近**：它们共享同一组**历史观测**输入（现价、每股股息、PB、ROE），差异主要来自"要求回报/要求股息率"这一假设的取值。
- ⚠️ **接近 ≠ 准确**：同一份报告曾用失真的锚点（PE 18x / PB 3.2x / 股息率 1.2%）算出"看起来落在区间内"的结果 —— 输入错，结果对只是巧合。
- ⚠️ **不得**为求收敛删除 DCF，也**不得**对四者静默取平均。

## 四、本版仍未完成的部分（登记，不假装齐备）

1. **两阶段 / 三阶段显式预测期**尚未实现：`valuation.py` 目前只覆盖单期永续；旧版 `07` 的"5 年显式增长 + 永续"是用外部表格手算的，本版**没有**把它重算成代码，因此 2.3 的 EV 是**由旧版结果反推**的（已在文中标明"反推"）。
2. **股权资本成本 Ke 未内置 CAPM 展开**：无无风险利率 / 贝塔的口径约定，Ke 只能作为外部输入。
3. **本示例未做新的数据源取数**：所有数字沿用旧版 `07` 的记录，**没有**重新拉取行情，因此**不能**作为当下时点的估值结论使用。
