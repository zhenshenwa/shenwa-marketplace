### 关键模式：偏差是**同向的**，且会叠加成错误的估值结论

| 维度 | 深挖方向 | 实际 |
|---|---|---|
| 毛利率 | 偏低（18~22%） | 23.93% |
| 净利率 | 偏低（8~11%） | 15.63% |
| 营收增速 | 偏低（18%） | 54.80% |
| 股息率 | 偏低（1.2%） | 2.80% |
| **盈利基数整体被系统性压低** | | |
| PE | **偏高**（18x） | 15.98x |
| ROE / ROIC | **偏高**（12.8% / 9.2%） | 12.08% / 8.37% |
| PB | 偏低（3.2x） | 3.64x |

> **结论**：深挖用「**偏低的盈利基数 × 偏高的 PE 倍数**」推导出 **DCF 基础值 ￥345**，进而得出"较现价折价 15%、安全边际充足"。而数据源显示实际 PE 仅 **15.98x**、归母净利率 **15.63%**——**深挖的"安全边际"是双重失真输入的产物，不可采信**。

### 衍生的方向性误判（重要）

深挖称 "ROE 12.8%、ROIC 9.2%，**均高于 WACC 8.5%**"。
按数据源：**ROIC 实际 8.37% < WACC 8.5%** → **深挖的"资本回报高于资金成本"这一核心论断，在 ROIC 维度上不成立**。属于**方向性误判**级别的问题，须在成稿中显式纠正。

## 六、校验结论

1. **拦截级 2 项**（股息率 1.2%、营收 CAGR 18%）→ 直接作废，且整段依赖它的表述一并删除。
2. **6 项显著偏差** → 采用数据源值，脚注标注深挖原值。
3. **深挖 3 处数字锚点（PE 18x / PB 3.2x / 股息率 1.2%）本身即失真**，导致其全部估值推演（B1~B6）建立在错误输入上 → **估值类数字整体作废**。
4. **方向性误判 1 处**（"ROIC 高于 WACC"）→ 必须在成稿中纠正为「ROIC 8.37% 略低于 WACC 8.5%」。
5. **事件类信息（C4）全部未获独立确认** → 不得进入情景推演。
6. 深挖的**可用价值**：① DCF+PB-ROE+股息率 的**估值方法框架**；② 「盈利质量—资本开支—分红」的**分析路径**；③ 「政策/技术/供应链」三类事件的**跟踪指标设计**。这三项不依赖其数字，可保留。
