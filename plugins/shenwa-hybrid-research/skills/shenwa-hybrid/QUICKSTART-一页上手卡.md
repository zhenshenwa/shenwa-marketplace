## 第 1 步 · 选你的风格（四选一）

| 你是什么类型 | 选它 | 一句话 |
|---|---|---|
| 长线配置，重现金流与安全边际 | **价值稳健** | 宁可错过，不可做错 |
| 抓产业趋势，容忍高估值换增长 | **成长挖掘** | 看渗透率与增长斜率 |
| 跟随量价与资金，中短线为主 | **趋势交易** | 跟趋势，不预测基本面 |
| 因子暴露与统计规律，要可回测 | **量化因子** | 要可复现，不要故事 |

**怎么用**：复制 `presets/` 下对应文件的内容，整体覆盖 `profile.yaml`，改掉 `client_name` 即可。**一项都不用选。**

## 第 2 步 · 想细调的话，只改这 5 个字段

不想逐项配置的人，改这 5 个就够：

| 字段 | 含义 | 可选值 |
|---|---|---|
| `identity.primary_style` | 投资风格 | value / growth / trend / quant |
| `identity.horizon` | 时间视角 | long / medium / short |
| `identity.risk_tolerance` | 风险容忍度 | conservative / balanced / aggressive |
| `identity.conclusion_bias` | 结论表述倾向 | conservative / neutral / aggressive |
| `output.depth` | 报告深度 | brief / standard / dd |

其余 13 项全有默认值。全部 18 项的含义见 `03A-偏好选项库.md`；也可以在 `03B-偏好选择表单.md` 上打勾。

## 第 3 步 · 提一个任务

一句话就够，剩下的由系统补齐。例如：

> 「分析一下比亚迪现在值不值得看」
> 「新能源汽车行业今年的竞争格局怎么变」
> 「帮我看看昨天市场发生了什么」

系统会自动完成：判定标的层级 → 选深挖模板 → 并行取数 → 交叉校验 → 出六段交付物。

**你要知道的唯一一件事**：深挖报告生成需要 **3~10 分钟**，期间会先把数据层交付给你，不会空等。

## 你会拿到什么

六段结构，固定格式：

| 段 | 内容 | 来源 |
|---|---|---|
| 1 结论摘要 | 3~5 条结论，按你的风格口径写 | 综合 |
| 2 事实底座 | 行情、财务、资金、机构预期，全部标来源与时点 | **数据源** |
| 3 分析主体 | 深度分析与逻辑推演，原文完整 | **深挖** |
| 4 校验表 | 逐项核对数字，标注一致 / 偏差 / 拦截级 | **数据源** |
| 5 风险与情景 | 风险清单 + 三档情景，每条落到可观察指标 | 综合 |
| 6 数据溯源与免责 | 来源清单、缺口说明、免责声明 | 综合 |

完整样例见 `validation/06-六段成稿示例-比亚迪.md`。

## 三条红线（保护你）

**① 数字只认数据源。**
深挖的分析框架很专业，但它的数字不可靠——实测 45 项数字一致率仅 33%，还出现过"股价 220 元"（实际 84.34 元）这种量级错误。所以：**已披露财报科目可用；推算类比率、估值目标价、买卖阈值一律由数据源提供。** 深挖在这套模式里的价值是**框架与逻辑**，不是数字。

**② 拦截级错误不会进入你的报告。**
偏差超过 50%、量级错误、方向性误判的结论，直接作废，不会用"双值并列"的方式变相保留。

**③ 未经确认的事件不参与推演。**
突发事件必须由公告或权威媒体独立确认后才进入情景推演；无法确认的单列，不算概率。

## 想改它？

没问题，这套模式就是给你改的。

| 你想改 | 怎么改 | 安全性 |
|---|---|---|
| 风格、周期、风险、输出形态 | 直接改 `profile.yaml` | 安全，随便改 |
| 关注池、市场范围 | 改 `profile.yaml` 对应字段 | 安全 |
| 校验严格度 | 改 `crosscheck_tolerance` | 安全 |
| 数据源 | 满足 D1~D8 能力契约即可替换 | 安全 |
| 分工比例 | 受浮动规则约束，需写明理由 | 受控 |

**偏好不是一次性的。** 用着不顺手，直接在对话里说（「以后结论保守一点」），即时生效；若同一类反馈连续出现 3 次，系统会建议写进配置文件长期生效。

**不要改的**：`01` / `02` / `04` / `05` 是主干逻辑，客户改了会破坏模式的可复制性。有需求告诉维护者。

## 常见疑问

**Q：为什么不能只让深挖做完全部？**
实测过。深挖剥离数据后会退化成"骨架表"（会用 `X%`、`Y%` 占位符），因为它拿不到实时数据。数据源有准确数字但给不出结论。两者各占一半不是折中，是刚需。

**Q：为什么还要一个校验表，不是重复劳动？**
因为深挖的数字错得比想象中多。没有校验层，那三个量级错误会直接写进你的结论摘要。

**Q：结论能直接拿去下单吗？**
不能。产出为 AI 辅助生成，数据来自第三方，可能存在延迟或口径差异。**重大投资决策前请人工复核一手来源（交易所公告、公司年报）。**
