## 第 1 步 · 选你的风格（四选一）

| 你是什么类型 | 选它 | 一句话 |
|---|---|---|
| 长线配置，重现金流与安全边际 | **价值稳健** | 宁可错过，不可做错 |
| 抓产业趋势，容忍高估值换增长 | **成长挖掘** | 看渗透率与增长斜率 |
| 跟随量价与资金，中短线为主 | **趋势交易** | 跟趋势，不预测基本面 |

**怎么用**：复制 `presets/` 下对应文件的内容，整体覆盖 `profile.yaml`，改掉 `client_name` 即可。**一项都不用选。**

## 第 3 步 · 提一个任务

一句话就够，剩下的由系统补齐。**两类问法走两条路，区别很大，值得分清**：

| 你想要 | 例子 | 走哪条路 | 代价 |
|---|---|---|---|
| **横截面 · 要名单** | 「**今天哪些行业和概念出现了右侧确认**」「**排一下今天否决最多的板块**」 | 接口直取（不发报告） | **0 点、秒级**，出四张表 + 计数 |
| **纵深 · 要解读** | 「**PCB 板块现在处于右侧哪个阶段，成因是什么**」「分析一下比亚迪现在值不值得看」 | 发深挖报告 | **5 点/标的**，1~5 分钟（个别超 10 分钟） |

其他常见问法：

> 「新能源汽车行业今年的竞争格局怎么变」
> 「帮我看看昨天市场发生了什么」

系统会自动完成（**v1.7.0 起按六步顺序**）：**① 看问题 → ② 看对象与数量 → ③ 看你到底要哪类指标 → ④ 看时间 → ⑤ 看到底要名单还是要推演 → ⑥ 看手上有什么能力**；再判定标的层级 → 选深挖模板（**并与 `tid=2001 智能深度推理` 做一次择优比较**；注意 2001 是**个股级**，行业/板块任务不会转过去）→ 并行取数 → 交叉校验 → 出交付物。
> **一个关键变化**：以前系统看到「排名 / 哪些 / 三个以上」就往横截面走，容易把「比较三家公司的盈利质量」也当成扫描。现在**这些词只影响「一次取一个还是一次取一批」，选哪条路由看你问的是哪类指标**（右侧状态 / 乖离率 / 估值 / 财务，各走各的）。
> **还有**：数据够解释时，系统会**直接给数据 + 一句简析**，**不强制发报告**。**「要名单」那类不进模板、不花点数。**

**你要知道的唯一一件事**：需要深挖写报告时，生成要 **1~5 分钟、个别超过 10 分钟**，期间会先把数据层交付给你，不会空等；而**"要名单"那类秒级返回、不花点数**。

## 你会拿到什么

**按任务给形态，不按篇幅**（v1.9.0）：简单任务简洁交付，复杂任务保留必要证据。

| 形态 | 什么时候 | 你会看到 |
|---|---|---|
| **短答** | 只问一个事实 | 一句结论 + 关键依据 + 哪里还没核实 |
| **比较表** | 两个以上对象对照 | 对照表 + 口径 / 截面说明 + 差异归因 |
| **简析** | 数据已够解释 | 数据 + 一句判断 + 证据状态 |
| **完整报告** | 需要完整推演（单标的纵深） | **六段结构**（见下） |

**「完整报告」的六段**（**只有这个形态**用六段；其他形态不必套）：

| 段 | 内容 | 来源 |
|---|---|---|
| 1 结论摘要 | 3~5 条结论，按你的风格口径写 | 综合 |
| 2 事实底座 | 行情、财务、资金、机构预期，全部标来源与时点 | **数据源** |
| 3 分析主体 | 深度分析与逻辑推演；**归档件完整保留全文**，正文只放认可的部分 | **深挖** |
| 4 校验表 | 逐项核对数字，标注一致 / 偏差 / 拦截级 | **数据源** |
| 5 风险与情景 | 风险清单 + 三档情景，每条落到可观察指标 | 综合 |
| 6 数据溯源与免责 | 来源清单、缺口说明、免责声明 | 综合 |

> ⚠️ **无论哪种形态，深挖原文都完整归档**；正文没附全文时，会给你归档入口。
> **形态可以简化结构，不会删掉关键依据与限制。**
> 完整样例见 `examples/宁德时代-价值稳健/`。

## 四条红线（保护你）

**① 财报数字与全部数值都只认数据源。**
深挖的分析框架很专业，但它的数字不可靠——实测 45 项数字一致率仅 33%，还出现过"股价 220 元"（实际 84.34 元）这种量级错误。所以：**财报类数据（营收/净利/毛利率等）一律直接从数据源取**；推算类比率、估值目标价、买卖阈值同样由数据源提供。深挖在这套模式里的价值是**框架与逻辑**，不是数字。

**② 拦截级错误不会进入你的报告。**
偏差超过 50%、量级错误、方向性误判的结论，直接作废，不会用"双值并列"的方式变相保留。

**③ 未经确认的事件不参与推演。**
突发事件必须由公告或权威媒体独立确认后才进入情景推演；无法确认的单列，不算概率。

**④ 接入只走 API，不要邀请码。**
深挖全程通过 API 调用，不会打开浏览器抓取；登录**只需要你的注册手机号，不需要邀请码、不需要密码**。主站访问不了时会**自动切到备用站**继续跑，不用你操作。

**⑤ 改偏好不会改事实。**
风格、风险容忍度、结论语气只改变**怎么说**（顺序、措辞、强调、版式），**不改变**客观判断、关键数字与证据状态——**不会**因为你选了"进取"就提高上行情景的概率。想看不同假设，直接说"按 XX 假设再算一遍"，系统会**标为「假设变化」**，不会当成事实。

## 想改它？

没问题，这套模式就是给你改的。

| 你想改 | 怎么改 | 安全性 |
|---|---|---|
| 风格、周期、风险、输出形态 | 直接改 `profile.yaml` | 安全，随便改 |
| 关注池、市场范围 | 改 `profile.yaml` 对应字段 | 安全 |
| 校验严格度 | 改 `crosscheck_tolerance` | 安全 |
| 数据源 | 满足 D1~D8 能力契约即可替换 | 安全 |
| 分工比例 | 写明理由即可 | 受控 |
| 交付形态（短答/比较表/简析/完整报告） | 直接说"简短点 / 给我完整报告" | 安全（关键依据不删） |

**偏好不是一次性的。** 用着不顺手，直接在对话里说（「以后结论保守一点」），即时生效；若同一类反馈连续出现 3 次，系统会建议写进配置文件长期生效。

**不要改的**：`01` / `02` / `04` / `05` 是主干逻辑，客户改了会破坏模式的可复制性。有需求告诉维护者。

## 常见疑问

**Q：为什么不能只让深挖做完全部？**
实测过。深挖剥离数据后会退化成"骨架表"（会用 `X%`、`Y%` 占位符），因为它拿不到实时数据。数据源有准确数字但给不出结论。两者各占一半不是折中，是刚需。

**Q：为什么还要一个校验表，不是重复劳动？**
因为深挖的数字错得比想象中多。没有校验层，那三个量级错误会直接写进你的结论摘要。

**Q：结论能直接拿去下单吗？**
不能。产出为 AI 辅助生成，数据来自第三方，可能存在延迟或口径差异。**重大投资决策前请人工复核一手来源（交易所公告、公司年报）。**

**Q：要给我一个邀请码吗？**
不用。深挖登录**只需要注册手机号**，不需要邀请码，也不需要密码。如果有谁向你索要邀请码，那是旧版副本，找分发者换新版即可。本专家全程只通过 API 访问深挖，不会打开浏览器抓取。

**Q：深挖主站打不开怎么办？**
不用管。系统会自动切换到备用站继续跑，无需你确认或操作。

**Q：为什么有的问题秒回、有的要等几分钟？**
因为有两类任务。「**要名单**」（今天哪些行业出现右侧确认）走的是**接口直取**——一次拿全 **62 个行业与主题指数**，**秒级、0 点**，只给你四张表、不编故事；「**要解读**」（某个板块为什么涨、接下来怎么走）需要深挖真的写一份报告，**5 点、1~5 分钟**。系统自己分，你不用选。

**Q：我只让它"查一下这个数字"，它却给我写了一份报告？**
A：那不该发生。**只查询**或**只整理你给我的材料**这类请求，**不会**自动扩展成新的深度研究。想要报告，直接说"做一份完整研究"。

**Q：结论有时一句、有时一大篇，为什么不一样？**
A：看**任务深度与问题类型**，不看篇幅——一个事实给**短答**，多个对象给**比较表**，数据够解释给**简析**，需要完整推演才给**完整报告**。无论哪种，**关键依据和"哪里还没核实"都会写清楚**，深挖原文都完整归档。

**Q：为什么老提 `tid=2001`？**
2001「智能深度推理」是一个**不预设分析维度、按需求自适应**的通用**个股**模板。系统每次选模板前都会拿它比一次——**这是刻意设计的择优动作，不是固定用 2001**。⚠️ **不是因为「问题多 / 维度多」就改用它**：只有在**本层级的专项模板覆盖不了你已列出的问题**、且任务层级为个股时，才会改选 2001；其余情况保留更专的模板。
